YHUP PT1500-H10
===============

The YHUP PT1500-H10 board uses the Realtek RTL9617C SoC and provides a
2.5-Gigabit Ethernet port together with gigabit Ethernet ports.

Build target
------------

.. code-block:: bash

   make pt1500-h10-2p5g_defconfig

The default device tree is:

.. code-block:: none

   rtl9617c-pt1500-h10-2p5g

Board files
-----------

The board implementation is under ``board/yhup/pt1500_h10/``. The board
Kconfig sets the YHUP vendor, PT1500-H10 model and RTL9617C SoC metadata.

The common SoC nodes are provided by ``arch/arm/dts/rtl9617c.dtsi``. The board
DTS adds the PT1500-H10 nodes, flash partitions and board-specific aliases.
