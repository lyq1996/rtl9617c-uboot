Youhua PT1500-H10-CT
===============

The Youhua PT1500-H10-CT board uses the Realtek RTL9617C SoC and provides a
2.5-Gigabit or 4-Gigabit Ethernet port together with gigabit Ethernet ports.

Build target
------------

.. code-block:: bash

   make youhua-pt1500-h10-ct-2p5g_defconfig

The default device tree is:

.. code-block:: none

   rtl9617c-pt1500-h10-ct-2p5g

Board files
-----------

The board implementation is under ``board/youhua/pt1500_h10_ct/``. The board
Kconfig sets the Youhuavendor, PT1500-H10-CT model and RTL9617C SoC metadata.

The common SoC nodes are provided by ``arch/arm/dts/rtl9617c.dtsi``. The board
DTS adds the PT1500-H10-CT nodes, flash partitions and board-specific aliases.
